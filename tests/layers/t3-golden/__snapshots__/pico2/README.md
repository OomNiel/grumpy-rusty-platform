# snapshot-project

Embassy firmware for **Raspberry Pi Pico 2** (`RP2350`), generated by
Grumpy's Rusty Platform for VS Code.

- Target: `thumbv8m.main-none-eabihf`
- debug probe chip id: `RP235x`

## Build / flash

```sh
cargo build          # compile
cargo run --release  # flash and attach defmt logs (uses the cargo runner in .cargo/config.toml)
```
